# Помощник настолок

Партии в настольные игры: выбор игры, дополнений, места и игроков, подготовка с картинками и озвучкой,
колесо первого игрока, раунды и очки, шпаргалка по правилам с поиском, история и статистика.
Одно веб-приложение в `app/`: на ПК оно работает внутри Electron, на телефоне — в браузере (PWA).

**Телефон:** https://koleso-app.github.io/board-helper/ (тот же сайт, что у «Колеса недели», поэтому видно его подключение к GitHub) — каждый push в `main` публикуется сам (`.github/workflows/pages.yml`).

## Запуск

```bash
npm install
npm start          # программа для Windows
npm run web        # то же в браузере: http://127.0.0.1:5180
npm run web:lan    # открыть с телефона в той же Wi-Fi-сети (адрес напечатается)
npm test           # проверки движка и подсчёта очков Flip 7
npm run dist       # установщик для Windows в dist/
```

## Как устроено

- `app/js/games.js` — движок: шаги подготовки с условиями, кто ходит в каком раунде, суммы, конец игры, поиск по правилам.
- `app/games/<игра>.js` — данные одной игры: подготовка, правила своими словами, частые вопросы, калькулятор раунда.
- `app/js/app.js` — экраны; `wheel.js` — колесо; `speech.js` — чтение вслух; `rules.js` — шпаргалка.
- Данные хранятся в `localStorage` устройства. Копия — в Настройках (файл JSON).
- Синхронизация (`js/sync.js` — шифрование, GitHub, слияние; `js/cloud.js` — очередь и повторы):
  зашифрованный паролем файл `nastolki.enc.json` в закрытом репозитории (тот же `koleso-data`, что у «Колеса недели»).
  Каждое изменение сначала сохраняется на устройстве и помечается «ждёт отправки»; уходит через 3 с, при появлении
  связи, при открытии приложения и раз в минуту, пока что-то ждёт. Слияние — по каждому игроку, месту и партии:
  побеждает более позднее изменение, удаления запоминаются. Настройки (тема, голос) остаются на устройстве.

## Новая игра

Создать `app/games/<id>.js` по образцу `flip7.js`, подключить его в `index.html` и `sw.js`.
- `expansions: [{ id, name }]` — дополнения; шаг подготовки показывается, если `when: c => c.has("<id>")`.
- `when: c => c.players > 18` — условие по числу игроков; `text` может быть функцией от `c`.
- `rounds.rotate`: `"left"` — первый игрок сдвигается каждый раунд, `"none"` — не меняется.
- `scoring.target` — до скольких очков; `calc` — карточный калькулятор раунда (или без него — ввод числом).

## Картинки и книга правил (только для себя)

Книги правил и картинки из них — в локальной `sources/` (не публикуется) и в закрытом `koleso-data`
(`nastolki-assets/<игра>/<имя>.webp`); приложение берёт их по токену синхронизации и кэширует на телефоне.

```bash
node scripts/assets/extract.mjs sources/<игра>.pdf sources/<игра>.txt           # текст книги для голосового помощника
node scripts/assets/render.mjs sources/<игра>.pdf sources/<игра>-pages-hi 8     # страницы картинками
node scripts/assets/crop.mjs sources/<игра>-pages-hi sources/assets/<игра> scripts/assets/<игра>-crops.json
```

Вырезки описываются в `scripts/assets/<игра>-crops.json` (рамка в единицах страницы шириной 864),
в игре — поле `images` (обложка, картинки шагов подготовки и разделов правил). WebP ~70%: Flip 7 весь ~230 КБ.
